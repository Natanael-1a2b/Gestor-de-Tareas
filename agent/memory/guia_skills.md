# Guía de Skills del Agente - Gestor de Tareas

Este documento describe las habilidades (skills) instaladas, su ubicación y cuándo deben ser utilizadas por los agentes.

## Ubicación de las Skills
Todas las skills se encuentran en: `agent/skills/`

---

## 1. `vercel-react-best-practices`
- **Ubicación**: `agent/skills/vercel-react-best-practices/`
- **Cuándo usar**: 
    - Al crear nuevos componentes React.
    - Al configurar hooks personalizados e implementar lógica de negocio.
    - Para asegurar que el código sea de nivel profesional (Vercel Standards).

## 2. `web-design-guidelines`
- **Ubicación**: `agent/skills/web-design-guidelines/`
- **Cuándo usar**:
    - **Crucial**: Para cumplir con el requisito de diseño "Premium".
    - Para validar que la jerarquía visual, tipografía y contrastes sean correctos.
    - Para asegurar que las acciones principales se realicen en **máximo 1-2 clics**.

## 3. `vercel-react-view-transitions`
- **Ubicación**: `agent/skills/vercel-react-view-transitions/`
- **Cuándo usar**:
    - Al implementar transiciones entre estados de la app (ej. abrir modales, cambiar de vista).
    - Para dar ese toque de "fluidez" y micro-animaciones que diferencian una app común de una de alta calidad.

## 4. `react-vite-best-practices`
- **Ubicación**: `agent/skills/react-vite-best-practices/`
- **Cuándo usar**:
    - Durante el setup y configuración del entorno con Vite.

## 5. `find-skills`
- **Ubicación**: `agent/skills/find-skills/`
- **Cuándo usar**:
    - Para buscar nuevas capacidades si las actuales no son suficientes.

---
*Nota: El agente DEBE consultar estas guías antes de iniciar cualquier fase de desarrollo.*
